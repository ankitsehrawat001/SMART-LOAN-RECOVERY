# Smart Loan Recovery System

A single-page Streamlit application for exploring a trained borrower-risk classifier. Enter a borrower profile to see the model's high-risk score, its predicted class, and a score-based suggested next step. The interface also includes a feature-importance chart, a risk gauge, and an interactive 3D view of income, loan amount, and outstanding balance.

> **Important:** This project is an educational prototype, not a validated lending or collections system. The current model predicts a risk flag created from manually named borrower clusters; it was not trained directly on observed loan recovery outcomes. Therefore, its score must not be interpreted as a verified probability that a particular loan will or will not be recovered. Do not use it as the sole basis for contacting a borrower, making a lending decision, or taking legal action.

## What the app includes

- A borrower form for the ten numeric inputs expected by the saved Random Forest model.
- Starting input values based on the means recorded by the saved `StandardScaler`.
- A model classification and estimated probability for class `1` (the notebook's higher-risk flag).
- A feature-importance chart showing each feature's relative contribution across the trained Random Forest. Importance is not a causal explanation for an individual prediction.
- A risk gauge and an interactive 3D borrower profile after submitting the form.
- Suggested follow-up bands: above 75% recommends focused human review and recovery outreach; 50% through 75% suggests reviewing settlement or repayment-plan options; below 50% suggests routine reminders and monitoring.

## Requirements

- Python 3.12 or another Python version compatible with the pinned scikit-learn release.
- The project dependencies listed in `requirements.txt`.
- Both saved model artifacts in the same directory as `app.py`:
  - `loan_rf_model.joblib`
  - `loan_scaler.joblib`

These artifacts must match the features and ordering expected by the app. Do not load joblib artifacts from untrusted sources.

## Run on Windows

Open PowerShell in the project directory and run:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit prints a local URL, usually `http://localhost:8501`. Open that URL in a browser. To stop the server, press `Ctrl+C` in the PowerShell window.

If you are not using the included `.venv`, create and activate your own virtual environment, install the requirements, and run `streamlit run app.py`.

## Model inputs

Enter age, monthly income, loan amount, loan tenure in months, interest rate, collateral value, outstanding loan amount, monthly EMI, number of missed payments, and days past due. Monetary inputs are shown in dollars, following the notebook's interface labels. The model receives the original numeric values in the exact feature order used when it was trained; the scaler is used to provide reference starting values, not to transform the prediction input.

## Understanding the model

The notebook constructs `High_Risk_Flag` from its manually assigned borrower-segment names, then trains a Random Forest on that flag. Its reported 88% accuracy measures predictions of that constructed label on the notebook's held-out split. It does **not** establish 88% accuracy for predicting actual recovery or non-recovery. Before any real-world use, the target should be defined from a reliable observed outcome such as `Recovery_Status`, the model should be retrained using an appropriate validation process, and its calibration, fairness, and performance should be independently assessed.

The score is the classifier's `predict_proba` output for class `1`. The suggested action is a simple rule based on that score; it is not generated by a separate policy-learning model. Have a qualified person verify input data and review any proposed action.
